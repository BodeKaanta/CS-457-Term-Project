$ python3 server.py -h
usage: server.py [-h] -p PORT [-v]

Networked Pente game server. Listens on 0.0.0.0 (all interfaces) and hosts one
two-player game room.

options:
  -h, --help            show this help message and exit
  -p PORT, --port PORT  TCP port to listen on (the project uses 5457)
  -v, --verbose         also log every message sent (DEBUG level)

Example: python3 server.py -p 5457
(exit status 0)

$ python3 client.py -h
usage: client.py [-h] -i HOSTNAME -p PORT [-a ALIAS]

Terminal client for networked Pente. Connects to the game server, shows the
board, and sends your moves.

options:
  -h, --help            show this help message and exit
  -i HOSTNAME, --host HOSTNAME
                        server DNS hostname, e.g. server.kaanta.edu (resolved
                        with DNS)
  -p PORT, --port PORT  server TCP port (the project uses 5457)
  -a ALIAS, --alias ALIAS
                        your player name: 1-16 letters, digits or '_' (asked
                        if omitted)

Example: python3 client.py -i server.kaanta.edu -p 5457 -a Alice
(exit status 0)
